Biological pathways are intentionally simplified: particles follow idealized routes that communicate key concepts rather than molecular-scale stochastic chemistry.

Annotation

Cytoplasm and cell overview

This model shows a stylized animal-like eukaryotic cell. Transparent materials reveal organelles and moving molecular particles. Click any label or timeline stage to learn more.

Tip: enable mitosis mode to see chromosomes condense, align, separate, and divide into two daughter cells.

WebGPU is not available in this browser

This simulation is written for the WebGPU API. Open it in a recent Chromium-based browser or another browser with WebGPU enabled. The file contains no external libraries or assets.

Because WebGPU requires a compatible graphics stack and secure context in many browsers, local testing may work best from a simple local web server.
