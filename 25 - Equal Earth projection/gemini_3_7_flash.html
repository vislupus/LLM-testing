Equal Earth Projection • Mathematical Equations & Solver

Exact forward/inverse equations by Bojan Šavrič, Tom Patterson, Bernhard Jenny (2018)

1. Forward Projection Formulation: $(\lambda, \phi) \longrightarrow (x, y)$

Given latitude $\phi \in [-\frac{\pi}{2}, \frac{\pi}{2}]$ and longitude difference $\Delta\lambda = \lambda - \lambda_0 \in [-\pi, \pi]$:

1. Parametric latitude $\theta$:
$\sin\theta = \frac{\sqrt{3}}{2} \sin\phi \implies \theta = \arcsin\left(\frac{\sqrt{3}}{2} \sin\phi\right)$
2. Coordinates $x$ and $y$:
$x = \frac{2\sqrt{3}\,\Delta\lambda\cos\theta}{3\left(9 A_4 \theta^8 + 7 A_3 \theta^6 + 3 A_2 \theta^2 + A_1\right)}$
$y = A_4 \theta^9 + A_3 \theta^7 + A_2 \theta^3 + A_1 \theta$
Polynomial coefficients: $A_1 = 1.340264,\; A_2 = -0.081106,\; A_3 = 0.000893,\; A_4 = 0.003796$
2. Inverse Projection Formulation: $(x, y) \longrightarrow (\lambda, \phi)$

Because $y$ is a 9th-degree polynomial in $\theta$, $\theta$ is solved from $y$ using Newton-Raphson iteration:

$f(\theta) = A_4 \theta^9 + A_3 \theta^7 + A_2 \theta^3 + A_1 \theta - y$
$f'(\theta) = 9 A_4 \theta^8 + 7 A_3 \theta^6 + 3 A_2 \theta^2 + A_1$
$\theta_{k+1} = \theta_k - \frac{f(\theta_k)}{f'(\theta_k)} \quad (\text{Initial guess } \theta_0 = y)$
Recover $\phi$ and $\lambda$:
$\phi = \arcsin\left(\frac{2}{\sqrt{3}} \sin\theta\right)$
$\lambda = \lambda_0 + \frac{\sqrt{3}\,x\left(9 A_4 \theta^8 + 7 A_3 \theta^6 + 3 A_2 \theta^2 + A_1\right)}{2\cos\theta}$
