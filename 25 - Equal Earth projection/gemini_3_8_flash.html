Equal Earth Map Projection Mathematics

Created by Bojan Šavrič, Tom Patterson, & Bernhard Jenny (2018)

The Equal Earth projection is an equal-area pseudocylindrical projection designed to balance continental shape aesthetics with true relative area preservation. Unlike the Gall-Peters projection, which stretches shapes severely, and Robinson, which is not equal-area, Equal Earth keeps all areas strictly proportional while retaining visually harmonious curved meridians.

Standard Constants (Spherical Formulation):
A₁ = 1.340264
A₂ = -0.081106
A₃ = 0.000893
A₄ = 0.003796
M = √3 / 2 ≈ 0.8660254037844386

1. Forward Projection (Latitude φ, Longitude λ ➔ Projected x, y)

For latitude φ ∈ [-π/2, π/2] and longitude λ ∈ [-π, π] in radians:

θ = arcsin( M · sin(φ) )
y = θ · ( A₁ + A₂·θ² + θ⁶·(A₃ + A₄·θ²) )
denom = M · ( A₁ + 3·A₂·θ² + θ⁶·(7·A₃ + 9·A₄·θ²) )
x = ( λ · cos(θ) ) / denom

Notice: Parallels depend solely on θ (and hence φ). Thus, all parallels in Equal Earth are straight horizontal lines!

2. Inverse Projection (Projected x, y ➔ Latitude φ, Longitude λ)

Given Cartesian projected coordinates (x, y), we solve for θ using Newton-Raphson iteration:

Initial Guess: θ₀ = y
f(θ) = θ · ( A₁ + A₂·θ² + θ⁶·(A₃ + A₄·θ²) ) - y
f'(θ) = A₁ + 3·A₂·θ² + θ⁶·(7·A₃ + 9·A₄·θ²)
θₖ₊₁ = θₖ - [ f(θₖ) / f'(θₖ) ] (converges in 4-8 steps to < 10⁻¹²)
Then latitude and longitude:
φ = arcsin( sin(θ) / M )
λ = M · x · [ A₁ + 3·A₂·θ² + θ⁶·(7·A₃ + 9·A₄·θ²) ] / cos(θ)
Full Bidirectional Coordinate Pipeline in this App:

Screen Pixel (clientX, clientY) ⟷ (SVG Matrix inverse) ⟷ SVG User Units (X, Y) ⟷ (Scale factor S = 320) ⟷ Equal Earth Projected (x, y) ⟷ (Equal Earth Inverse / Forward) ⟷ Geographic Coordinates (φ, λ).
