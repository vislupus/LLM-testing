An educational board game

The Etymologist

Every English word is an immigrant. Follow one home.

❦

You are a word-archaeologist. A modern English word will appear; beneath it lies a branching system of ancestral roots. Descend three forks — Family, Source, and Root — to trace the word back to its origin.

Each fork awards ★. Five words in a session. Before each word, roll the Scholar's Die for a single-use bonus. Wrong choices still advance the lantern — you'll always see the true path — but you'll earn no star for that fork.
