THERM-2D Physics & Engineering Reference

Numerical Heat Equation Simulation on a 2D Discrete Grid

The 2D Heat Diffusion & Advection Equation

Thermal transport through continuous heterogeneous media combines Fourier conduction, fluid convection, and Newton cooling:

∂T / ∂t = ∇ · (α ∇T) - (v · ∇)T - h(T - T_amb)

Where T is temperature field, α = k / (ρ·c_p) is thermal diffusivity, v is velocity field (thermal buoyancy / fan wind), and h is Newton cooling to ambient.

Harmonic Interface Fluxes

To properly simulate real-world thermal contact resistance between different materials (e.g. Copper next to Aerogel), interface conductivities are evaluated using the harmonic mean:
α_int = 2·α_A·α_B / (α_A + α_B).

CFL Stability Criterion

In 2D explicit Euler finite-difference methods, stability demands:
r = α_max · (Δt / Δx²) ≤ 0.25. The simulator automatically divides updates into sub-steps so the simulation never diverges into unphysical oscillations.
